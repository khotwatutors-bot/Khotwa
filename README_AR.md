# خُطوة — نظام التشغيل v0.5

**الإصدار 0.5 هو ترقية تشغيلية Full-stack للموقع المنشور.** يضيف استقبال طلبات مركزيًا وإدارة داخل الموقع، لكنه يحتاج ربط قاعدة D1 والأسرار ثم إعادة النشر قبل استقبال العملاء الحقيقيين.

## ما يفعله الإصدار 0.5

- يحافظ على موقع خُطوة العربي والإنجليزي وكتالوج الخدمات والموضوعات والسلة.
- يرسل الطلب من الموقع مباشرة إلى `/api/requests`؛ لا يحوّل العميل إلى Google Forms.
- يحفظ الطلب في Cloudflare D1 ويصدر رقم طلب بعد نجاح الحفظ فقط.
- يضيف لوحة إدارة خاصة على `/admin/` بكلمة مرور مدير محفوظة كـ Secret، وجلسة HttpOnly موقعة.
- يسمح للمدير بمراجعة بيانات العميل والخدمات المطلوبة، وتغيير حالة الطلب، وتسجيل السعر المتفق عليه والدفع ومواعيد التسليم والمتابعة والملاحظات.
- يسجل إحصاءات اختيارية لاستخدام الموقع بعد موافقة الزائر: مشاهدات الصفحات والإضافة إلى السلة وبدء الطلب. لا يجمع هوية الزائر من مجرد التصفح.
- يوفر تكاملًا اختياريًا مع Google Sheets وGmail عبر Apps Script لنسخ الطلبات وإرسال الإشعارات.

## مهم قبل اعتبار الموقع جاهزًا

هذه حزمة كود وإعداد. لا تصبح وظائف قاعدة البيانات ولوحة الإدارة نشطة على الموقع الحي إلا بعد إنشاء D1، وتشغيل `schema.sql`، وضبط أسرار المدير، وتحديث Build command وإتمام نشر ناجح. اتبع ملف `OPERATIONS_SETUP_AR.md` بالترتيب.

## لوحة المدير

بعد الإعداد والنشر افتح:

`https://YOUR-KHOTWA-WORKER.workers.dev/admin/`

استخدم كلمة مرور المدير التي وضعتها في `ADMIN_PASSWORD`. لا تضع كلمة المرور أو `SESSION_SECRET` في GitHub أو ملفات الواجهة العامة.

## مسار الطلب

العميل يختار خدمة/موضوعًا في الموقع → يملأ نموذج الموقع → يرسل → Worker يتحقق من المدخلات ويكتب الطلب في D1 → يحصل العميل على رقم مرجعي → يظهر الطلب في لوحة المدير. يمكن تفعيل Google Sheets وGmail كنسخة وإشعار إضافيين.

## حدود الإصدار

- الموقع يستقبل **طلبات خدمات**؛ لا يوجد حاليًا تحصيل مدفوعات أو اشتراك ذاتي أو بوابة دفع.
- إضافة منتج للسلة لا تعني شراءً ولا تكشف هوية الزائر. الإحصاءات مجهّلة ومشروطة بالموافقة.
- العملاء الذين لا يرسلون النموذج لا يمكن معرفة أسمائهم؛ يمكن فقط تسجيل أحداث استخدام مجهّلة بعد موافقتهم.
- مرشد خُطوة ما زال مرشدًا محليًا قائمًا على قواعد توصية، وليس مساعد ذكاء اصطناعي متصلًا.
- Google Forms لم يعد مطلوبًا لمسار طلب الخدمة في هذا الإصدار.

## ملفات الإصدار

- `worker.js`: API وحفظ الطلبات والجلسات الإدارية والإحصاءات.
- `schema.sql`: مخطط قاعدة D1.
- `admin.html`: لوحة المدير.
- `site/index.html`, `site/assets/js/app.js`, `site/assets/css/styles.css`: واجهة العميل وربط الإرسال.
- `Google_Notifications_Code.gs`: تكامل Google الاختياري.
- `OPERATIONS_SETUP_AR.md`: الإعداد الكامل والنشر والاختبار.
